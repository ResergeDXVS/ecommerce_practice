# 🛍️ VivaRopa- HTML, CSS and JS Project

## 📖 Description
A practice e-commerce project created to exercise a front-end workflow with HTML, Sass and JavaScript. It is a static web page that puts into practice the core building blocks of an online store interface, without frameworks or build tools required to run it.

## 🛠️ Technologies used
- **Main language:** JavaScript
- **Markup & styling:** HTML5, Sass (SASS/SCSS) compiled to CSS
- **Frameworks:** None (vanilla JavaScript)
- **Database:** None
- **Tools:** Any static file server or a plain web browser

## 📂 Project structure
- `index.html` — Main page of the store
- `css/` — Compiled stylesheets
- `js/` — JavaScript logic
- `img/` — Image assets

## 🚀 Getting started

### Prerequisites
- A modern web browser
- (Optional) A local static server such as the VS Code *Live Server* extension
- (Optional) Sass, if you want to recompile the stylesheets from source

### Installation
```bash
git clone https://github.com/ResergeDXVS/ecommerce_practice.git
cd ecommerce_practice
```

### Run
Open `index.html` directly in your browser, or serve the folder with a local server:
```bash
python -m http.server 8000
```
Then visit [http://localhost:8000](http://localhost:8000).
